# Miro Store

Next.js 14 + Supabase. Shaarar linen ah, gelitaan email, dalab, Dashboard admin.

## Orod (local)
    npm install
    cp .env.example .env.local
    npm run dev

## Env (Vercel > Settings > Environment Variables)
    NEXT_PUBLIC_SUPABASE_URL
    NEXT_PUBLIC_SUPABASE_ANON_KEY

## Supabase (Authentication > URL Configuration)
Site URL = link-ga websaydhkaaga (tusaale https://miro-store.vercel.app)
Redirect URLs = isla link-gaas.

## Admin
Email-ka ku jira shaxda `admins` ayaa arka Dashboard-ka.

## EVC
Dalabku wuxuu galaa xaaladda Pending; admin-ku wuxuu calaamadeeyaa "La bixiyay" marka lacagta la xaqiijiyo.
WaafiPay (EVC Plus) waa lagu dari karaa route server-side ah oo beddela xaaladda dalabka.
